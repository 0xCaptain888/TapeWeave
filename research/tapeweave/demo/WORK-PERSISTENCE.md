# 通用作品执行与安全交付

日期：2026-10-18。以下为已实现本地功能，不是主网应用、独立采用或安全审计。

## 1. 版本比较与回退

在 `manage.html` 保存同一库内标识的两个版本。点击“以v1为基准”再“比较v2”，输出标题／说明／场景变化，以及八行转换中每个变化的输入和前后输出。`same_behavior`只比较经过重编译核对的行为SHA，不代表场景或业务语义相同。

“回退至v1（追加）”把旧内容追加为新版本；保留全部历史。目标与当前内容相同会拒绝，20版上限仍生效。不会迁移玩家进度、撤销接收者版本或更新其他应用。

## 2. 作品库备份

点击“生成作品库备份”，手动复制归档到自己安全位置。恢复时粘贴到空库并点击恢复。逐件检查并重新编译作品；格式／散列／非空库／存储异常均拒绝，失败不覆盖。上限2 MiB，最多100作品×20版本；没有合并、删除或认证。备份不含执行进度。清理站点数据前必须自行保留归档；不要为了测试删除唯一副本。

## 3. 浏览器执行

`work.html`操作成功后写入本机执行日志，恢复时逐步重算；64步上限，模式随存档恢复。重新生成、装载和重置会开始新存档。已检测到外页变更会停用旧页；比较文本不提供跨页CAS、对抗恶意篡改或ABA保护。

## 4. Node24通用SQLite执行适配器

不同于旧四回合训练／门宿主，新 `work-store.mjs`直接消费完整作品包，支持trigger和recharge两输入、byte／plain、64步、命令ID和预期版本。它是本地开发者适配器，**没有接到Pages或旧HTTP服务**，也不自动执行实际奖励。

先把作品包保存为仓库外 `/private/tmp/my-work.json`，数据库也放仓库外：

```sh
node research/tapeweave/demo/work-cli.mjs /private/tmp/my-work.sqlite create trial /private/tmp/my-work.json byte
node research/tapeweave/demo/work-cli.mjs /private/tmp/my-work.sqlite act trial charge-1 0 0 1
node research/tapeweave/demo/work-cli.mjs /private/tmp/my-work.sqlite act trial use-1 1 1 0
node research/tapeweave/demo/work-cli.mjs /private/tmp/my-work.sqlite show trial
```

默认蓄能作品第二步应request=1；重复原命令ID和相同参数返回相同日志，不追加；同ID不同输入拒绝。关闭进程再show保留进度。并发调用先在事务外校验／重算，再在`BEGIN IMMEDIATE`内比较原始日志、提交；冲突者拒绝，可用原ID重试。WAL、FULL、busy_timeout=5000；提交异常回滚。不在等待异步重算时持有写事务。

测试包含重开、两模式、重试、冲突、双连接竞争和提交前故障回滚；未新增进程断电／磁盘损坏测试，不把旧宿主的SIGKILL证据移植到这里。没有钱包认证、公网访问控制、云备份、链消费或效果事务。应用应把奖励与状态放在同一受控事务里，不能先发奖再调用本地适配器。没有迁移浏览器日志到SQLite的UI。

## 5. 180秒演示拍摄提纲（尚未拍摄）

- 0–25秒：明确任务——一个创作者行为交给两个不同应用使用；当前两个应用仍为作者示例。
- 25–65秒：在作品管理查看八行蓄能规则，生成作品包，展示行为SHA。
- 65–110秒：展览应用A领取／揭开，B仍零状态；B领取／兑换，库存归零，重复兑换被应用拒绝。
- 110–140秒：相同任务切普通模式，明确普通代码也可实现，尚未证明成本优势。
- 140–165秒：版本比较／追加回退，恢复执行日志，展示未认证记录。
- 165–180秒：真实制造历史单独标注；本演示未发链动作，独立接入与商业验证尚缺。

不能把提纲当成视频成片、把作者应用当客户、把本地SQLite当链上应用。外联、广播及投稿仍未执行。
