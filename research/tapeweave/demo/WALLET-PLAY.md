# 浏览器钱包试玩与恢复

更新：2026-10-26。使用 `chain.html` 顶部的“用自己的钱包玩一局”。页面为静态前端，请通过 HTTPS 或 localhost 打开。

## 操作

1. 在安装 OKX／MetaMask 插件的浏览器中打开，选择实际检测到的钱包，点击 **Connect Wallet**。支持 EIP-6963 发现及传统注入接口，钱包名称只作显示，不作身份认证。
2. 使用 X Layer 主网，chain ID **196**。若网络不符，点击切换后重新连接。当前钱包必须已配置 X Layer；页面不自动添加未知网络。
3. 选蓄能或交替卡，点击“预览新局”。页面核对固定宿主完整运行时代码、账户类型、RPC 网络，模拟合约调用并显示原生币转入、gas、单价与费用上限。
4. 核对后点“确认并打开钱包”，再在钱包中确认。每一步都是独立确认；连接钱包和预览本身不会发送交易。
5. 点击“核验交易回执”。至少两个区块深度后，核对交易、规范块、事件及块末会话，取得你的会话 ID。
6. 依次预览并确认 **等待 → 等待 → 触发 → 触发**，每次核验后继续。蓄能卡最终训练2分、开门1次、余钥匙1；交替卡最终训练1分、开门0次、余钥匙2。也可以自行选择四次输入。

本入口只接受普通 EOA 插件账户。具有代码的 AA／委托账户被明确阻止，请使用已有[官方 AA 钱包操作工具](../../../docs/tapeweave-host-run-2026-10-26.md)。插件提供商可能有不同的 AA 接口，当前没有把 `eth_sendTransaction` 当成完整 UserOperation 接口。

主网宿主无代币授权、无转入价值、无领奖或兑换功能。**插件钱包交易可能需要 gas。** 预览以当时公共 RPC 参数为准，给估算 gas 增加20%余量，显式填写 gas、gasPrice、nonce；若钱包修改费用，仍须核对钱包的最终提示。历史官方 AA 运行的0费用不能推出所有用户免费。

## 预览与版本保护

- 仅允许固定的已发布主网宿主。完整 runtime（含不可变配置）与前端固定 SHA-256 比较，不依赖 JSON 中的“成功”标记。
- 预览60秒有效。发送前再次核对钱包账户和网络、代码、会话全部状态、nonce、模拟与费用；上涨或状态变化要求重新预览。
- `act` 包含确切版本，其他页面先推进会话会导致当前请求停止或链上回滚，不会自动换版本重发。
- 账户、网络、提供商、输入选择改变或页面隐藏会使预览失效。采用 Web Locks 排斥同一来源的并发发送；不支持该接口的浏览器仍可只读。
- 公共 RPC 的只读请求按间隔发送。网络／429错误会显示出来，可以重新读取或预览；不自动重试交易。

## 结果不明、刷新或关闭页面

调用钱包**之前**先把公开操作意图保存到 localStorage，返回哈希后更新。存储不可用时禁止发送。保存的只有账户、调用、前置状态、时间及哈希，**没有私钥、助记词、API Key 或签名**。

有待处理记录时禁用新的发送。刷新后不需要先连接钱包即可点击核验原交易：

- 已有哈希：点击“核验交易回执”，待确认时稍后再次点击。
- 钱包未返回合法哈希、网络异常或页面在签名期间关闭：查看钱包历史，把完整交易哈希填入恢复框。必须匹配原账户、宿主、calldata、value、chain ID 与 nonce，不能用别人的成功交易替代。
- 钱包明确返回用户拒绝（4001）时清除该意图；其他错误保留为结果不明，避免重复开局。
- 已确认回滚：显示实际 gas 费用，清除待处理记录，重新读取并决定是否再预览。不会自动发送。
- 核验成功后先保存本机历史，再清除待处理意图。刷新后连接原账户，在“我的会话”选择并重新读取即可续用，也可手填 ID。

**不要通过清理站点数据解决未知交易。** 本机记录不是云备份。若长期找不到哈希，需要人工检查钱包历史／浏览器恢复记录，不能把“不知道结果”当成“没有发出”。交易被钱包替换但 calldata 或 nonce 不匹配时，本页拒绝认领，应人工处理。

## 我的会话、交易历史与备份

“我的会话”按当前账户区分，显示已核验开局／动作对应会话和本机最后观察版本；回滚交易保留费用，但不会创建虚假的新会话。断开或切换账户会清空当前列表视图，不删除其他账户的本机缓存。缓存版本不是最新链状态，点击“读取所选会话并续用”会核完整宿主代码及实际归属后读取当前状态。

“生成历史备份”输出已核验的公开意图／回执、块引用、费用和发现的会话。它不包含当前待处理意图、密钥或钱包登录资料。“校验并合并”会严格限制字段、网络、宿主、数量与大小，重复记录去重，冲突／损坏拒绝；失败不覆盖原历史。最多500笔回执、1000个发现会话、1 MiB，无自动清理旧记录。达到上限时核验历史保存会停止且保留待处理意图，请先导出备份并人工处理，不把它当无限容量服务。

导入仍是**未签名缓存**，不因格式正确而变成可信链证据。不能自动连接、授权发送或替代待处理恢复。当前账户列表内选择后必须重新读取链上状态。

“从链上发现已有会话”只查询固定宿主当前账户的 `Opened` 事件，校验范围、事件字段与规范区块；每次最多100块、100事件，默认起点为已发布部署块。也可填入已知开局交易附近的十进制区块。成功后移到下一段，失败保留起点，用户显式点击继续。不自动扫描全链，不宣称空结果代表该账户从未开局。扫描可找到用官方 AA 工具开的会话，网页发送仍保持 EOA 限制。

单端日志发现只用于找会话 ID，不代表完整交易费用／全部动作已核验。发现记录与本机回执分开展示。当前没有云端账户索引、自动定位替换交易、后台扫描或跨设备自动同步。

## 核验边界

主网页下方另有“用两个端点交叉核验（只读）”，不要求连接钱包，也不触发发送。固定使用`rpc.xlayer.tech`和`xlayerrpc.okx.com`；先校验两端网络及高度，高度相差超过128块即停止，取较低链头减两块作为固定查询高度。两端区块哈希必须相同、完整宿主runtime的SHA-256必须匹配前端固定值、会话状态必须一致，随后分别重读区块哈希；任何端点不可用、格式错误、状态差异或期间区块改变都显示失败，不回退成双端成功。仅支持当前已发布固定宿主。选择改变会丢弃旧异步结果。

这是当前会话的两URL一致观察，两端可能共享基础设施，不证明独立提供商共识或最终性，不持续监控后续重组。它不重验历史11笔交易，也没有替代钱包发送前预检、回执核验和日志发现的单RPC路径；这些路径仍按下述边界理解。

验证交易 `from/to/input/value/nonce/chainId` 与原意图，成功状态、至少两块深度、规范块、唯一宿主事件、玩家归属、卡片、版本、输入与预测效果，及该块末会话。若同块还有后续动作，会注明块末状态包含后续推进。

这里是**单公共 RPC**观察，不是双提供商共识、签名重验或最终性保证；RPC欺骗、浏览器插件被替换、页面来源被攻破不由该流程解决。确认回执后页面不持续监控深度重组。宿主固定了处理器地址并在每个动作检查网表与真值转换，浏览器不把处理器可变代码当成已审计保证。

## 自动验证

`node research/tapeweave/demo/check.mjs` 包含钱包模块与历史／发现故障场景；`--browser` 包含真实 Chrome 点击正式页面的模拟钱包流程。覆盖两卡四步重算、网络／账户／版本改变、费用变化、拒签、未知哈希、刷新恢复、存储失败、回执／事件／代码／区块不符、历史导出合并、跨账户隔离及新文档恢复。

本机故障测试及浏览器回归使用作者控制的 EIP-1193 与 RPC 替身，**不等于实际插件签名验收**。独立的公网Chrome只读检查使用正式HTTPS页面与真实RPC，验证两会话读取、两端点交叉比较和限定范围开局查询，不替换fetch、不连接或签名。这次开发不新增主网交易。已有11笔真实 AA 交易仍单独记录在[主网运行说明](../../../docs/tapeweave-mainnet-run-2026-10-26.md)。

参考接口：[EIP-1193](https://eips.ethereum.org/EIPS/eip-1193)、[EIP-6963](https://eips.ethereum.org/EIPS/eip-6963)、[EIP-3326](https://eips.ethereum.org/EIPS/eip-3326)。
