## 新增：有限行为工作室

打开 [studio.html](studio.html)：编辑8行转换表，编译本地NAND/LATCH字节，在训练／钥匙门两个独立宿主消费；普通共享真值表享有同等规则。编辑后须重新编译；编译或切模式清零。此入口是独立实验schema，可导出并在工作室粘贴校验装载（16 KiB上限）；不是任意网表上传，不能导入旧固定两卡挑战／回放入口。成功装载清零且保持执行模式；失败保留当前局。完成四回合后还可生成双宿主未认证回放，并粘贴到“仅复核，不装载”检查（32 KiB上限）。默认0011应复核得训练2、门1；改任一得分再复核应失败且当前局不变。普通模式同样可生成。配置变化清空旧导出；修改复核文本清空旧结论。回放可被任何人自造，不证明玩家、时间或链消费。动作提交前会检查存档是否已被另一页面修改，检测到差异则拒绝且不推进；检查与写入不是原子操作，仍不支持多标签并行。浏览器探针已增加导入、双宿主回放及新同源文档恢复检查，本轮增加启动预检：Chrome连about:blank都在10秒内未返回，在加载TapeWeave之前即失败（独立空白页诊断也15秒超时），不能归因于页面或宣称UI通过。超时会终止本次启动的独立进程组，并等待退出再清理临时目录，不会终止既有Chrome。可用CHROME指定本机可用的兼容浏览器可执行文件；启动预检成功不代表UI通过。十一组Node本轮通过，含子进程超时／错误退出与离线文件校验检查；浏览器与手机验收仍未完成。无链身份；新增同源localStorage配置／动作恢复（可用时）。工作室作者Chrome行为探针已在实际1100／500宽各通过10项，手机触摸、视觉及平台人工验收仍未完成。

## 新增：创作包离线执行

Node 24下，在仓库根目录执行：

```sh
node research/tapeweave/demo/play-creator.mjs research/tapeweave/demo/creator-artifact-example.json 0011 > /tmp/tapeweave-creator-play.json
node research/tapeweave/demo/verify-creator.mjs replay /tmp/tapeweave-creator-play.json
# 同等规则的普通共享表对照：
node research/tapeweave/demo/play-creator.mjs research/tapeweave/demo/creator-artifact-example.json 0011 --ordinary
```

输入可换为工作室导出的创作包；先完整校验（16 KiB上限、严格UTF-8），再从零执行四拍，同时生成训练／钥匙门结果。输出为现有回放schema，可粘贴工作室复核。默认示例应训练2、门1剩1钥匙；普通模式除plain标记外结果一致。输入文件不被修改；JSON写到标准输出，命令本身不保存会话、不修改网页localStorage／SQLite、不提供事务重试或身份认证。每次执行都是新局，不是历史恢复。重定向请使用新的输出文件，勿覆盖输入。示例是作者合成，不是玩家研究或真实链回执。

## 新增：不依赖浏览器的创作包／回放校验

需要Node 24，无新增依赖。在仓库根目录运行：

```sh
node research/tapeweave/demo/verify-creator.mjs replay research/tapeweave/demo/creator-replay-example.json
node research/tapeweave/demo/verify-creator.mjs artifact /你保存的创作包.json
```

示例是作者合成的蓄能0011记录，不是真人结果。成功应显示`valid: true`、训练score 2、门score 1／resource 1、`authenticated: false`和`chain_identity: null`。可把浏览器导出的JSON保存为本地文件后使用相同入口；回放与创作包分别限32／16 KiB，拒绝非法UTF-8，JSON重复键取最后值。改动score／sha256应非零退出并显示校验失败；参数错误退出2，其余拒绝退出1。此命令只读输入文件，不修改存档、不联网，也不独立认证作者引擎的正确性或历史真实性。

## 1. 从哪里打开

在任务变更审查中找到 [index.html](index.html)，点击预览按钮。页面需要同目录的 CSS／MJS，以及上一层的参考包，不能只复制 HTML。

如已在自己的电脑取得本仓库，可在仓库根目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8000/research/tapeweave/demo/index.html`。按 Ctrl+C 停止服务。仅绑定本机，不是公开部署；不要在包含敏感文件的其他目录启动服务。直接双击 HTML 可能因相对 fetch 限制无法启动。

## 2. 一条完整的手动体验路径

1. 选择“蓄能”、训练、窗口 `0011`、电路字节。
2. 第一拍预测选 `0`：初态没有能量，同拍补能不会立即输出；下一状态为1。
3. 依次点击等待、等待、触发、触发。请求应为 `0,0,1,1`，得分为2。结束后不能继续操作。
4. 在“交付挑战包”填写标题与说明，生成 JSON，选择并复制文本。包的 `chain_identity` 应为 null；不含玩家成绩。
5. 改成另一卡或窗口，粘贴刚才的包并“校验并装载”：恢复原配置与说明，当前局清零并重新要求预测。执行模式保持原选择。
6. 再完成第2—3步，点击“生成四回合回放”。它应包含四位动作 `0011`、4行轨迹、score 2、authenticated false。
7. 将回放粘贴到“复核一份回放”，点击“仅复核，不装载”：显示计算一致及未认证提示。把回放 score 改成3再次复核，应失败；当前局不变。
8. 切“普通公式”，重复同一挑战：操作、导出、导入与复核能力相同，结果不应因对照模式而降低。

这条路径是操作说明，不是已经执行的真人体验记录。它不检验玩法是否有趣、创作者是否愿意使用或开发者是否降低了接入成本。

## 3. 出错与恢复

| 情况 | 预期行为／恢复方式 |
|---|---|
| 页面提示参考包读取失败 | 使用支持相对资源的预览或上述 HTTP 服务；保留目录结构 |
| 未预测，操作按钮禁用 | 先选择预测答案；答错也能继续并看到解释 |
| 包摘要、规则或初态被改坏 | 导入报错，当前局与配置不变；恢复原包再试 |
| 未完成四回合 | 回放生成按钮禁用 |
| 修改标题、说明或配置 | 旧导出清空；配置变化还会清零当前局 |
| 修改复核输入 | 旧复核结论清空，需再次点击复核 |
| 刷新或关闭页面 | 当前局与未另存的文本丢失；没有持久作品库 |

包与回放粘贴入口限制 UTF-8 文本为64 KiB；仅接受固定两卡、零初态、四回合规则和固定预测题。浏览器 JSON 重复键取最后值后校验，Python动作文件入口拒绝重复键，不能声称两者完全等价。说明只作为文本，不执行HTML。

## 4. 开发者复算命令

推荐在仓库根目录执行统一入口，无需新增 npm 依赖：

```sh
node research/tapeweave/demo/check.mjs
# 显式开启本地Chrome交互检查：
node research/tapeweave/demo/check.mjs --browser
```

默认顺序运行下列前四组Node检查，不启动服务或浏览器；任一失败或单组超过120秒即停止并返回非零退出码。`--browser`才追加Chrome探针（该探针会启动临时本地HTTP服务）。统一入口只汇总现有作者检查，不新增独立验证或价值证据；未知参数拒绝执行。

需要单独定位时仍可运行：

```sh
node research/tapeweave/demo/test-engine.mjs
node research/tapeweave/demo/test-host-boundaries.mjs
node research/tapeweave/demo/test-package.mjs
node research/tapeweave/demo/test-replay.mjs
node research/tapeweave/demo/browser-check.mjs
```

前四条分别覆盖有限引擎、同步内存宿主边界、固定挑战包和回放一致性。最后一条需要本机 Chrome，默认路径为 macOS 的 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`；可通过 `CHROME` 环境变量指定其他安装路径，但其他系统尚未验证。浏览器探针创建临时本地服务与配置目录，完成后清理；通过DOM事件自动操作，不是真人点击或触屏测试。

同步内存边界检查现通过66次拒绝调用的输入不变断言、双模式宿主隔离、4组冻结输入的局中失败／合法重试对照及4组历史日志对象隔离检查；不提供重复提交去重、持久事务或历史轨迹认证，详见[接入指南第5.1节](../INTEGRATION.md)。

作者当前受控检查：16转换、64最优参考回放、1024合成轨迹；64挑战包组合；1024动作序列两执行模式的回放往返与篡改拒绝；Chrome实际视口1100／500各24项检查。桌面Chrome没有得到请求的390宽视口，不能据此宣称手机已通过。平台预览、视觉、触摸与真人理解仍须分别验证。

## 5. 现在能证明什么，不能证明什么

- **已有：**固定材料范围内“说明编辑→包生成→粘贴装载→预测→四拍操作→解释→回放生成→复核”的作者本地实现。
- **没有：**任意电路创作、真实制造身份、钱包认证、持久原子宿主、真实链消费、独立接入、真人价值或商业验证。
- **回放边界：**别人可以自造合法轨迹并通过；计算一致不证明操作发生过，不是认证成绩或链回执。
- **公平对照：**普通公式获同等规则与交付能力。现有测试不能证明TapeOut独占能力或优于普通实现。
- **研究结论：**旧70分仍是历史设计基线，不因自测或功能数量增加而上调。下一个价值门槛是实际理解／创作任务和开发者接入收益，而不是继续堆页面。
