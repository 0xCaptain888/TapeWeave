# X Layer执行上下文补证：从处理器地址走到实现候选

> 研究／读取日期：2026-10-17，America/Los_Angeles。本轮仅公开JSON-RPC只读；无签名、交易、部署、storage override或第三方联系。结论限固定历史块，不是合约审计或当前实现承诺。

## 1. 这轮实际推进了什么

上一轮只知道协议草案建议记录beacon背后的实现，X Layer实际对应关系仍未知。本轮从**此前保存的X Layer运行时代码**出发，而不是直接套用BNB地址，追到一个共同beacon候选及其返回的实现地址。

固定区块：`0x4611346`，十进制73,470,790，与[原主网样本](tapeout-integrated-decision-2026-10-17.md)一致。

| 层级 | 实际观测 | 解释边界 |
|---|---|---|
| 三枚处理器 | `0x839bdd6fa7a66416a609a735e11de5411b98574e`、`0x0565ea48ca41ae559d8d491dbb0a9ec945db551b`、`0xe0ef4fffd869cbd24b2f83e6d2d83109937e05ff`的已保存runtime均295字节 | 仅原非随机前三样本，不是所有处理器 |
| runtime调用模式 | 精确前缀包含selector `0x5c60da1b`、一个32字节地址常量及后续STATICCALL序列 | 与向固定候选请求`implementation()`的模式一致；不是通用proxy检测器或完整反编译 |
| 共同候选 | `0xf70d1ed4f62cf3780157b0b421b7e2f45bd0991c` | 本轮在同一历史块查询，不从地址名称推断权限 |
| 候选返回 | 两端调用`0x5c60da1b`均返回`0x977f217887e085d298cb3819cdad5a0ee35f29b2` | 证明本次调用返回相同地址，不是已验证实现源码 |
| 候选／实现代码 | 两端均读到非空代码，分别619／12,562字节，字节相同 | 不等于源码验证、语义等价或安全证明 |

新采集8次请求：每端chainId、候选getCode、候选implementation调用、返回地址getCode各一次，4组成对响应一致。两个端点不是两个独立信任根；本轮没有新做最终性／重组验证。

代码：[implementation_context_probe.py](../research/tapeweave/implementation_context_probe.py)。原始返回及UTC读取时间：[xlayer-implementation-context-2026-10-17.json](../research/tapeweave/xlayer-implementation-context-2026-10-17.json)。运行命令：`python3 research/tapeweave/implementation_context_probe.py`；默认重新读取同一个固定块，不获取“latest”。依赖既有主样本与只读请求模块，无钱包依赖。

## 2. 哪些未知缩小了，哪些没有

**已缩小：**“X Layer样本根本找不到执行上下文”不再准确。现在有可重复的候选地址提取、调用结果与非空代码证据。处理器地址不应被单独当成完整语义身份；至少可以在证据中附上该块候选与实现返回。

**仍未知：**

- 未对实现12,562字节做完整反编译、验证源码／编译配置对应或差分语义证明。
- 未审计beacon权限、升级入口、控制主体、延迟、事件或历史变化。本次有这种间接模式，不证明实际发生过升级，更不证明任何人都能升级。
- 未建立外层工厂proxy的完整实现路径，也未追REF目标的实现上下文。因此**不能称已完成引用闭包或全协议身份绑定**。
- 未验证从检查到动作执行期间，实际宿主能否原子约束上下文；链下preflight不是防竞态机制。
- 未新采最新块，不能把历史实现地址写成当前配置。
- 未制造本项目两枚能力、持久消费或测量gas。历史样本不能充当本项目制品验证。

## 3. 对参赛方案的实际修订

主推仍是“创作者行为在不同应用复用”，但演示证据页不应只有NFT编号或网表哈希。首版待实现记录至少分为：

1. **制品身份**：chainId、processor、circuitId、网表与能力档案；
2. **执行上下文观察**：固定块、识别方法版本、候选／返回实现及原始代码证据；摘要应注明算法，不把本地SHA-256冒充EVM codehash；
3. **应用消费**：实例／状态版本、输入来源、动作授权、输出与效果，另行关联真实交易；
4. **证据状态**：已观察／未知／发生变化需复核；不显示“已安全认证”。

V1继续保持无REF、有限已审查集合。它降低闭包复杂度，但**没有消除共享实现变化风险**。变化时先暂停并重新核验，不继续展示过期的“已验证”标签。检查能否在实际宿主中有效执行仍须验证；本轮不实现通用监控或链上适配器。

## 4. 是否因此更适合冲奖

这轮提高的是**完成度设计与技术论证的可信度**，不是原创性、用户需求或获奖概率。它既说明X Layer不是只有BNB文档可参考，也暴露共享执行依赖应被显式处理。

如果最终作品只展示地址、哈希和代理关系，它仍然是技术证据页，不是有用户价值的玩法。前轮花园缺少双向取舍、普通函数可复现轨迹、独立接入缺失等反证均未被解决。排序仍为TapeWeave／TapeAction／TapeForge，不添加虚构分数。
