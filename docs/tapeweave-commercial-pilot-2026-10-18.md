# TapeWeave首轮商业验证任务单（未执行）

日期：2026-10-18。性质：作者设计的实验，不是官方活动规则、用户反馈或商业成果。依据见[商业价值复核](tapeweave-commercial-validation-2026-10-18.md)。本轮无新增外部事实断言，无外联、报价、收款或部署。

## 1. 只检验一个承诺

> 对已有两个互动应用的开发者，把同一有限状态规则交给两个宿主使用，并在规则修改后验证两边行为，是否比普通共享实现减少维护工作？

这不是“用户需要链上电路”的预设。若目标开发者只有一个应用、没有共享规则需求，或现有库已解决问题，应记录不匹配，而不是临时要求对方再造一个宿主。原生创新仍可保留小范围探索，但不能作为商业需求通过的证据。

当前两卡与训练／门宿主只是试验材料；它们不是客户的真实业务。只有参与者能提供近期真实任务，才进入商业任务对照；没有任务时本轮结论为“未取得需求证据”，而不是“已证明无人需要”。

## 2. 需求观察脚本（取得授权与同意后使用）

先不展示TapeWeave，不问诱导性的“如果有这个你会买吗”。逐项记录原话摘要和未知，不记录姓名、秘密或客户私有代码。

1. 最近一次需要在两个应用共享或更新行为规则是什么时候？具体改了什么？
2. 现在如何交付规则、测试和更新？已有库、共享合约或配置是否足够？
3. 最近一次实际花了多少时间，有没有发生错误？没有记录就标估计，不补造数字。
4. 谁负责选择工具、谁承担预算？当前是否为类似服务付费？不要求提供私人账单。
5. 下一个同类任务何时可能发生？如果没有，持续使用假设暂不成立。

不得把一次访谈同时计为开发者采用、付费及留存三份证据。参与者拒绝或撤回时停止记录与后续联系。

## 3. 同一任务、两条完整路径

先固定需求与验收，再交错体验顺序；熟悉度、作者帮助和先做一次的学习效应分别记录。首轮只做描述性比较，不做统计显著性或市场规模结论。

| 项目 | TapeWeave路径 | 普通共享路径 |
|---|---|---|
| 输入 | 同一规则真值表、时序与宿主约束 | 完全相同 |
| 允许工具 | 现有创作包、指南、求值器与回放 | 成熟共享模块／配置／共享合约及测试框架，不要求逐卡硬编码 |
| 首次交付 | 接到第一个宿主并通过固定转换 | 相同 |
| 第二宿主 | 同一规则接入；状态分开、宿主资源自行约束 | 相同，不要求复制实现制造劣势 |
| 更新任务 | 改动一个事先约定的行为并检查两个宿主 | 相同；版本化与回归能力均允许 |
| 最低验收 | 输出／新状态正确，宿主资源限制保留；错误输入不被静默当成功 | 相同 |

开始前确认现有工具能表达真实任务；表达不了则记录“不适用”，不在现场不断扩功能。新行为若不能由现有有限档案安全表达，不进入链上制造或真实宿主许可；可停止实验，而非修改审查白名单绕过。

测量从阅读输入开始至交付可验收结果的总时间；包括学习、接入、修改、排错与作者协助。记录结果为完成／失败／未完成；失败和中止不从汇总中删除。记录作者协助分钟、错误数与恢复方式，不能只比较最后一次成功运行的耗时。

**当前限制**：尚无独立开发者执行记录；作者重跑不能填充本表。使用作者解释器也不算独立协议实现或链上消费。

## 4. 付费检验卡（未报价，不接支付）

仅在任务确有价值后填写；先回答以下空项，再决定是否另行申请外联／报价／收款授权：

- 买方角色：____；预算决定者：____；当前替代：____。
- 服务交付：一个行为包、两个约定宿主的接入及固定回归报告（范围须按真实任务重写）。
- 排除：安全审计、无限维护、主网部署保证、收益保证、协议官方认证。
- 价格／计价单位／币种：**未确定**，不得代填“客户可接受价”。
- 预计作者工时／工具与运行成本／后续支持范围：____；不能只算链上费用。
- 报价有效期、交付完成条件、退款与争议处理：____，均待双方约定。

证据状态逐级记录：未询价 → 已展示报价 → 接受范围与价格 → 下单 → 实付；拒绝、取消和退款另记。接受报价不算收入，补贴／返款及作者自付不算自然付费需求。没有授权与适用支付路径前，不生成付款链接、不索钱包授权。

即使首单实付，也只证明这一单，不能推出订阅意愿、规模化毛利或长期留存。

## 5. 回访检验与分母

以首次完成真实任务的日期为起点。暂用7日探索窗口，仅为内部设计；任务周期超过7日时如实说明窗口不合适，不把“没到下次任务”认定为流失。

- 有效再次使用：在后续不同真实任务中再次交付、更新或回归；记录任务及完成结果。
- 单列：作者提醒后的使用、访谈回访、奖励驱动、测试刷新、重复导出。它们不计“主动再次使用”。
- 分母：已完成首个真实任务且已满7日观察的参与者；未满窗口列为待观察，不能计不回访。
- 输出：同时报告人数与比例，例如“主动再次使用a人／已满窗口b人，待观察c人”；b=0时比例为“不适用”，不填0%。这是本实验复用口径，不等于行业标准D7留存。
- 记录不回来的理由：没有新任务、普通方案足够、成本、难用或未知。没有后续记录不自动归因产品无用。
