# TapeWeave 当前开发状态

日期：2026-10-26。本页区分当前实现与历史阶段文档；早期“部署暂停”“只读草案”“尚无宿主消费”等表述只描述当时状态。

## 已实现

- 本地作品创作、接收、普通方案对照、版本比较与追加回退、执行日志和归档。
- Node24／SQLite 本机持久化与专用网页；不是公开多用户后端。
- X Layer AA 账户通过 CreateX 部署固定两卡宿主，并完成两局四步。11笔真实交易、事件及最终状态见[主网报告](tapeweave-mainnet-run-2026-10-26.md)。
- 网页普通 EOA 插件账户连接、代码与版本核对、模拟／费用预览、逐笔确认、回执核验、未知交易恢复。
- 当前账户本机会话列表、回执历史、备份导出与校验合并；选择历史会话后重新读取链上状态。待处理意图与已核验历史分开保存。
- 按固定宿主／当前账户的 `Opened` 事件进行只读分段发现。当前公共端点每次最多100块；用户显式推进扫描，不冒充完整全链索引。
- 主网页可显式点击“两端点交叉核验”，在较低链头减两块的同一高度比较区块哈希、固定宿主完整runtime及会话状态；两端重读区块以检测核验期间变化。失败不显示一致结果。
- HTML 初始化前禁用操作控件，脚本处理器就绪后启用；Chrome回归包含延迟真实模块加载的场景。
- AA独立入口：EIP-5792 2.0.0能力门槛、已部署账户、内部调用预览、费用确认、逐笔ID、未知恢复、固定EntryPoint成功UOP与宿主事件核验；与普通钱包待处理互斥，AA历史独立导出。
- 插件／AA／Android三套人工验收记录，默认未完成、通过／失败须观察、链上通过须哈希、本机草稿与JSON导出。只读ADB不安装、不解锁、不打印设备序列号；本机0台就绪设备。

钱包历史只是未签名本机缓存，导入不认证来源、不连接钱包、不授权发送。已核验回执写入历史成功后才清除原待处理意图；配额或记录冲突失败时保留原意图。清站点数据仍会丢失本机数据。

## 工程余项

| 内容 | 当前边界 |
|---|---|
| AA 网页 UserOperation 流程 | **开发完成**：连接、能力检测、预览、钱包签名请求、查询、恢复、回执核验均已实现；仅固定EntryPoint／已部署且声明supported账户。真实浏览器AA签名和兼容验收独立记录，尚无新增通过证据 |
| 独立提供商核验 | 网页已接两公开端点的显式只读比较；两端可能共享基础设施，不能声称独立来源共识。钱包发送前预检／回执及日志发现仍为单RPC |
| 完整 UOP 独立模拟 | 内部调用模拟及实际成功日志已有；缺少完整独立签名前模拟报告 |
| 自定义规则上链 | 本地可编辑，当前已部署宿主固定两张审查卡；扩展需新设计与审查 |
| 公网多用户持久化 | 目前是本机 SQLite 与浏览器存储；无云同步／公开账户后端 |
| 发布者认证 | 作品包有内容一致性检查；无发布者签名和可信版本防降级 |
| 完整历史索引 | 已有本机历史和显式区块扫描；无自动全链索引、替换交易自动定位或云端历史服务 |

这些并非全部都是当前演示的必需功能。扩展不替代独立用户任务与价值验证。
